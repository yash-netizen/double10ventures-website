# Double 10 Ventures — Website Mockup

Clickable mockup of the Double 10 Ventures website: Consulting & Projects and Supplies & Sourcing.

- The site lives in `mockup/`. Open `mockup/index.html`, or serve the folder with any static server.
- Product data and the shared header/footer are in `mockup/assets/site.js`; project data is in `mockup/assets/projects.js`.
- This is a review mockup. Product specifications, project details and images are subject to client confirmation, and enquiry forms do not send anything.
